About Voxbi

A cloud phone system, built in Luxembourg

Voxbi is a cloud-based phone system, hosted in the European Union. It replaces on-premises PBX hardware with a web app you can run from any browser, plus a native Windows desktop app and mobile apps for iOS and Android.

Your team manages users, call routing, queues, and live analytics from one browser tab: Voxbi Cockpit. Voxbi is built and supported by Mixvoip, a Luxembourg telecom operator building European telecom since 2008, and a Gold sponsor of the Odoo Community Association.

What you get in Odoo

Your phone system, inside Odoo

Automatic call logging

Every inbound and outbound call is saved to the caller's chatter with time, duration, direction, and who handled it.

Click-to-call from any record

One click on a contact, lead, or quote and your softphone or desk phone places the call.

Caller details on screen

See the caller's name, company, last calls, tickets, and activities from Odoo while the phone is still ringing.

What this app does

From API key to live integration

Connecting a phone system to your business software usually means raising a ticket, sharing credentials, and waiting on a vendor to wire it up.

This app adds a Voxbi → Configuration wizard to your Odoo backend. You paste an API key created in Voxbi Cockpit and click Install. The wizard registers this Odoo with Voxbi Cockpit, which then installs and configures the Voxbi integration for your database, with progress streaming back into the wizard as it happens.

Key features

Built for a one-step install

API key setup

No Odoo passwords to type or share. Create an API key with the "Is Odoo Installer" scope in Voxbi Cockpit, paste it, and install.

Live progress

The wizard polls the install status and shows a color-coded log console, so you can watch the provisioning happen step by step.

Optional SIP sync

Opt in to push SIP settings into Odoo's VoIP module after install, or keep your existing VoIP configuration untouched.

Admin-only

The setup wizard is restricted to Settings administrators. Connection identifiers are masked in the UI by default.

How it works

Three steps, then it runs itself

  1. In Voxbi Cockpit, go to Integrations → Add integration, choose API key, tick the "Is Odoo Installer" scope, and save. Copy the API key, which is shown like a password.
  2. In Odoo, open Voxbi → Configuration, paste the API key, review the data-sharing notice, tick the authorization box, and click Install.
  3. The wizard shows live progress and confirms once Voxbi Cockpit has configured the integration.

External service & data sharing

What gets shared, and with whom

This app requires Voxbi Cockpit, an external service operated by VOXBI S.A., to provision the Voxbi integration. When you click Install, the app asks for your explicit authorization and then sends the following to Voxbi Cockpit over an encrypted (HTTPS) connection:

  • The Voxbi Cockpit API key you pasted, to authenticate the request
  • This Odoo instance's URL, database name, Odoo version, and the version of this app
  • The login and user ID of the administrator running the wizard
  • A freshly generated Odoo API key for that administrator, used by Voxbi Cockpit to configure the integration over XML-RPC
  • Your chosen options (SIP sync, active flag)

The generated Odoo API key can be revoked at any time from the administrator's Preferences → Account Security. You retain full ownership of your data. A Voxbi account and an active Voxbi subscription are required to use this integration. See the privacy policy.
